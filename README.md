# CRED website clone (Frontend Assignment)

This project is a **frontend replication** of the CRED landing page, built as part of a hiring assignment. The goal was to recreate the **UI, layout, and interactions** as closely as possible using modern frontend tools.

---

## Tech Stack

- React (with Vite)
- CSS / Tailwind (or your styling choice)
- Vite (for fast development & build)

---

## Features

- Responsive landing page layout
- Hero section with background animation/video
- Smooth scrolling experience
- Recreated typography, spacing, and layout
- Component-based architecture
- Optimized asset loading

---

## Objective

The purpose of this project was to:

- Replicate the **look and feel** of the CRED website
- Demonstrate frontend development skills
- Showcase understanding of layout, styling, and UI behavior

---

## Disclaimer

This project is built **for educational and evaluation purposes only**.
